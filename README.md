# What would modern news look like in Shakespearean English?

This repo is a fork from my former manager, Director of Engineering at Commure and PatientKeeper, and friend, Drew Cohan.
I'm using it to experiment with LocalAI and small LLMs to determine which will run the fastest locally on my Windows 10 laptop: 
Surface Book I Performance Edition.

Once I find the small local LLM which runs the fastest, I will be adding a designed UI/front-end to this personal project --
most likely with Django (with Python in the backend) and either Vue.js or React.js.  So far, there is a bare bones front-end in Flask, 
and TinyLlama is the fastest local LLM I've tested yet.  However, even the TinyLlama LLM still is taking about 1 minute to 1 & 1/2 minutes
to retturn the translation.

I'm specifically testing local AIs and local LLMs because they're totally free -- at least, so far.  ;)
